# OpenSea Whitelist Checker — Downloads

This public repository contains compiled Windows installers and automatic-update metadata only.

The application source code is maintained separately in a private repository.

## Install

Open the latest release, download the Windows `.exe` installer, and run it.

Each user supplies their own OpenSea API key. Wallet private keys are encrypted locally using Windows protection and are never published here.

## Updates

Installed versions check this repository for new releases and prompt before downloading or installing an update.
